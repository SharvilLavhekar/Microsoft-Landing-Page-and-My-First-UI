# Microsoft Landing Page Clone

A responsive clone of Microsoft's homepage built from scratch to study and implement modern CSS layout models, semantic HTML structuring, and cross-device responsiveness without relying on UI frameworks.

---

##  Live Demo
[View Live Site](https://sharvillavhekar.github.io/Microsoft-Landing-Page-and-My-First-UI/)

---

##  Built With
- **HTML5:** Semantic structuring (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- **CSS3:** Modern layouts, custom styling, transitions, and media queries
- **Vanilla Setup:** Zero external frameworks or CSS libraries

---

##  Key Learning Objectives & Core Concepts

This project served as a hands-on exploration of CSS layout behavior and document flow:

### 1. CSS Flexbox
- Implemented unidirectional flow for navigation menus, utility links, and CTA banners.

### 2. CSS Grid
- Structured multi-column card displays and feature sections using two-dimensional layout rules.
- Managed explicit rows, columns, and grid auto-placement for balanced content organization.

### 3. Responsive Web Design
- Applied CSS `@media` queries with targeted breakpoints for desktop, tablet, and mobile displays.
- Handled dynamic viewport units, percentage widths, and relative sizing to avoid layout breaking on smaller screens.
